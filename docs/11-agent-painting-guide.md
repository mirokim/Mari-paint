# 에이전트 페인팅 가이드 — 헤드리스로 그림 한 장을 완성하며 배운 것 (2026-09-19)

`examples/meadow.py` 가 JSON 연산 7,200개를 만들고 `mari-paint --headless --script` 로 초원·구름·나무를 그린다
(1600×1000, 레이어 16장, 커스텀 붓 2개). 세 번 렌더해 보고 고치며 나온 규칙:

1. **그리기 연산에는 `layer` 를 항상 명시한다.** `layer.add` 가 새 레이어를 활성으로 만들지만(2026-09-19 수정),
   중간에 다른 층을 손대면 어디에 그리는지 헷갈린다. 생성기는 `cur` 로 현재 층을 추적해 자동으로 붙였다.
2. **에어브러시 긴 획은 쌓인다.** 불투명도 0.1 이어도 간격 10% 로 300번 겹치면 1이 된다. 넓고 옅은 안개·그늘은
   `select`(+`feather`) → `fill`(알파 색) 로. 에어브러시는 점(dab)이나 짧은 획에.
3. **`render` 는 기본 512px.** 세부를 보려면 `view:{mode:"full",max:1600}`. `--out-dir` 만 주면 연산마다 더티 PNG 가
   떨어지니 `--view none` 과 마지막 `render` 한 번.
4. **`view.layer` 는 id(정수).** 이름은 안 받는다 — `layer.list` 로 id 를 먼저 본다.
5. **Windows 셸에 한글을 `--exec` 로 넘기면 CP949 로 깨진다.** 한글 레이어·브러시 이름은 `--script <파일.json>`(UTF-8) 로.
6. **커스텀 붓은 JSON 으로 바로 만든다.** `brush.save {preset:{...}}` — 색 지터(풀), 랜덤 회전·크기(잎) 같은 걸 획마다
   안 시키고 붓에 넣으면 연산 수가 준다.
7. **큰 것부터, 어두운 것부터.** 하늘 그라데이션 → 먼 산(올가미+그라데이션) → 언덕 → 길 → 풀 → 나무(어두운 잎 → 밝은 잎,
   빛 방향으로 하이라이트 오프셋) → 그림자(타원 선택+페더+multiply) → 구름 → 새 → 비네팅.
8. **그림자·비네팅은 레이어 합성 모드로.** `layer.setProps blendMode:"multiply", opacity:0.7`.
